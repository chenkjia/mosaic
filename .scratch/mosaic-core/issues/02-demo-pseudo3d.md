# 02 demo1 伪 3D 宝石砖块复刻页

Status: todo
依赖：无
关联：REQ-001（视觉）、ADR-0002

## 目标

在 `apps/demo/demo1/` 做一张零构建静态校准页：用 Canvas 2D 复刻「马卡龙糖果风 + 圆角方砖 + 宝石质感」的棋盘，锁定砖块尺寸、缝隙、圆角、高光/内阴影/投影与配色。

## 验收项

- `file://` 直开，无构建、无依赖。
- 390×844、768×1024、750×1334 三种视口无溢出、无遮挡。
- 棋盘 21×28、格 34、内缩 1.5 的规格与 spec 一致；参数集中在规格表。
- 至少呈现普通/硬砖/障碍/奖励砖四种状态，硬砖带裂纹、障碍带斜纹（色弱冗余编码）。
- 页面附验收口径：对照基准、容差、核对项。
- 用户确认视觉后冻结；port 进 game 后归档不再改动。

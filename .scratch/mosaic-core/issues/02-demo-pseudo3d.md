# 02 demo1 伪 3D 宝石砖块复刻页

Status: in_progress
依赖：无
关联：REQ-001（视觉）、ADR-0002

## 目标

在 `apps/demo/demo1/` 做一张零构建静态校准页：用 Canvas 2D 复刻「马卡龙糖果风 + 圆角方砖 + 宝石质感」的棋盘，锁定砖块尺寸、缝隙、圆角、高光/内阴影/投影与配色。

## 验收项

- `file://` 直开，无构建、无依赖。
- 390×844、768×1024、750×1334 三种视口无溢出、无遮挡。
- 棋盘 21×28、格 34、内缩 1.5 的规格与 spec 一致；参数集中在规格表。
- 至少呈现普通/硬砖/障碍/奖励砖四种状态，硬砖带裂纹、障碍带斜纹（色弱冗余编码）。
- 页面附验收口径：对照基准、容差、核对项。
- 用户确认视觉后冻结；port 进 game 后归档不再改动。

## 实现与核验（待用户视觉确认）

- 产物：`apps/demo/demo1/index.html`、`demo1.js`、`README.md`（完整验收口径）。
- 规格：750 设计宽 / 最小高 1334；棋盘 21×28、格 34、内缩 1.5、714×952、圆角 7；16 色马卡龙调色板。
- 四态：普通 1 击；硬砖=裂纹 + hp 圆点（2/3）；障碍=斜纹；奖励=白菱形 + 星芒。障碍 6 块置于爱心内部，不悬空。
- 入口：`file://` 直开；`?view=` 或 `#view=` 模拟 390×844 / 768×1024 / 750×1334，按真实布局计算后等比缩放；`G` 网格、`H` 规格面板。
- 数据层：`node --check demo1.js` 通过；页面无 console 报错；`scrollWidth/Height` 与视口一致（无溢出）。
- 浏览器截图核验（701×781 实时 fallback、390×844 fit、768×1024 fallback、750×1334 fit）：四态可辨、图例完整、HUD 无遮挡；网格线与砖块边界对齐。
- 本轮修正：`file://` 下浏览器丢弃 query → 支持 hash；`CLEARED` 白字在浅底不可见 → 改深紫；障碍原本漂浮在爱心外 → 移入爱心内部；实时 badge 压住 HUD → 诊断文本移入画布底部留白；底部提示加深色胶囊底。
- 待办：用户确认视觉后冻结，再 port 进 game。

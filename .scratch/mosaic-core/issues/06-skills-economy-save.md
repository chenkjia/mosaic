# 06 技能、充能与本地存档

Status: done
依赖：03、04
关联：REQ-001（技能、失败线、存档）

## 目标

实现四格固定技能栏、单格充能、奖励砖掉落与本地存档；V1 不引入金币与扩容。

## 验收项

- 四格技能栏固定常驻（多球 / 加宽 / 激光 / 减速），每格最多 1 次充能；拾取只存入充能，点击（按下并抬手、未拖出格子）已充能格才释放，空槽进入广告补给确认。
- 每块奖励砖击碎必掉 1 次未满格技能充能；四格全满不生成掉落并提示；掉落越过失败线移除。
- 多球 +2（受 8 球上限）、加宽 ×1.4/15s、激光 10s、减速 0.7×/10s；同类刷新不叠加，异类可共存。
- 失败线 = 技能栏上沿；球与掉落物越过即丢失，全部球丢失判失败；重开本关充能清零。
- 存档键 `mosaic.save.v1`：`{version,highestLevel,sound,music}` 往返一致；旧档 `coins` / `slotCapacity` 丢弃且最高关保留；损坏/缺字段降级默认档；读写收口单点。
- 启动直接进入最高关预开局，无首页、无星级、无关卡选择页。

## 实施记录

- 产物：`game/saveStore.js`（唯一读写点）、`game/audio.js`（V1 no-op 接口）、`ui/skillBar.js`（四格常驻）、`ui/hud.js`、`game/layout.js`、shared 的 `addSkillCharge` / `activateSkill` / 掉落与 `failY` 规则。
- 决定（2026-10-22，取代本票初版）：初版「2 槽 + 金币扩容」在 Q39 改为固定四格充能后失去唯一金币用途，金币与 `slotCapacity` 一并从 V1 移除；存档迁移只保留最高关与音效/音乐。每格上限 1 次，来源为奖励砖（必掉）与激励视频。
- 后续（2026-10-22）：用户要求奖励砖必须有掉落，`skillDropChance` 由 0.5 改为 1；四格全满时发 `skillFull` 并 toast「四个技能都已就绪」。同时移除首页，启动直接进入最高关预开局；`scene/home.js` 与 `onExit` 删除。
- 后续（2026-10-22，拾取/释放分离）：用户反馈「一吃到技能就使用掉了，需要在下面点击」。数据层本就不会在拾取时激活，问题出在技能格 `pointerdown` 即释放：手指在技能栏上按下或拖动经过时会被误触发。`play.js` 改为 `slotPress` + 抬手确认——按下只记录格号/坐标/按下时充能状态，抬手仍在同格且位移 ≤ 18 才 `useSkill()`，拖出格、位移超限或按下时未充能均不释放；toast 改为「已就绪 · 点击下方释放」，空槽广告补给后为「已补充 · 点击下方释放」。
- 验证：`corepack pnpm test` 48 项通过（shared 覆盖自定义失败线、充能上限、奖励砖必掉、满格不生成掉落、旧档字段丢弃、拾取只充能不自动生效）；浏览器确认无首页直达最高关、四类弹层无 home、奖励砖掉落可被挡板拾取；四格常驻、空槽广告、广告中时间冻结、补给后充能 +1、拖动跨技能栏不断手；真实 PointerEvent 按下后拖出技能格不消耗充能，原地点击才释放。

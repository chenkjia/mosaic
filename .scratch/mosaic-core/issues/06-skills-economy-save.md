# 06 技能、减益与本地存档

Status: done
依赖：03、04
关联：REQ-001（技能、失败线、存档）

## 目标

实现四格固定技能栏（广告入口 + 状态显示）、技能接到即施放与本关永久叠加、减益掉落与本关永久层数、本地存档；V1 不引入金币与扩容。

## 验收项

- 四格技能栏固定常驻（大球 / 加宽 / 分裂 / 减速）；无充能、无点击释放、无时长限制；技能由奖励掉落被挡板接到或技能格广告看完直接施放。
- 奖励砖每块击碎必掉 1 个技能掉落物（金色菱形 + 图标），掉落池只含加宽/分裂/减速且只在当前仍能生效的技能中随机；池内技能都不可用时不生成掉落并提示；掉落物越过失败线移除，生成到接住之间该技能封顶则作废并提示。大球不进掉落池。
- 大球每关一次，所有球半径 ×1.6 并永久穿透（普通/奖励/减益砖进入即破，硬砖每次穿损 1 点，障碍与边界仍反弹，之后生成的球继承）；分裂（所有移动中的球各生成 1 颗同色球，±30°、同速，停泊球跳过，8 球上限阻塞，无移动球不可用）、加宽每层 ×1.4 封顶 2.0×、减速每层 ×0.85 封底 0.5×；加宽与减速本关永久叠加，过关/重开/下一关清零，复活保留。
- 技能格显示当前倍率；大球施放后、加宽封顶与减速封底显示「已满」，分裂无移动球显示「无目标」；不可用格点击不拉广告。
- 减益砖击破必掉对应类型掉落物（暗红菱形 + 图标），挡板接到才生效、漏接不生效；挡板缩短 0.65×/层、球速 1.3×/层、方向反转二元状态，本关永久；状态条只显示图标 + 层数，无倒计时、无 toast。
- 失败线 = 技能栏上沿；球与掉落物越过即丢失，全部球丢失判失败。
- 存档键 `mosaic.save.v1`：`{version,highestLevel,sound,music}` 往返一致；旧档 `coins` / `slotCapacity` 丢弃且最高关保留；损坏/缺字段降级默认档；读写收口单点。
- 启动直接进入最高关准备态（无开局弹窗），无首页、无星级、无关卡选择页；HUD 只显示递增的已清除/总数数字，无说明文字与清除率。

## 实施记录

- 产物：`game/saveStore.js`（唯一读写点）、`game/audio.js`（V1 no-op 接口）、`ui/skillBar.js`（四格常驻）、`ui/hud.js`、`game/layout.js`、shared 的 `addSkillCharge` / `activateSkill` / 掉落与 `failY` 规则。
- 决定（2026-10-22，取代本票初版）：初版「2 槽 + 金币扩容」在 Q39 改为固定四格充能后失去唯一金币用途，金币与 `slotCapacity` 一并从 V1 移除；存档迁移只保留最高关与音效/音乐。每格上限 1 次，来源为奖励砖（必掉）与激励视频。
- 后续（2026-10-22）：用户要求奖励砖必须有掉落，`skillDropChance` 由 0.5 改为 1；四格全满时发 `skillFull` 并 toast「四个技能都已就绪」。同时移除首页，启动直接进入最高关预开局；`scene/home.js` 与 `onExit` 删除。
- 后续（2026-10-22，拾取/释放分离）：用户反馈「一吃到技能就使用掉了，需要在下面点击」。数据层本就不会在拾取时激活，问题出在技能格 `pointerdown` 即释放：手指在技能栏上按下或拖动经过时会被误触发。`play.js` 改为 `slotPress` + 抬手确认——按下只记录格号/坐标/按下时充能状态，抬手仍在同格且位移 ≤ 18 才 `useSkill()`，拖出格、位移超限或按下时未充能均不释放；toast 改为「已就绪 · 点击下方释放」，空槽广告补给后为「已补充 · 点击下方释放」。
- 后续（2026-10-22，分裂与减益）：激光技能整体替换为分裂，`SKILL_IDS` 固定为 `multiBall/widePaddle/split/slow`；`activateSkill('split')` 无移动球时返回 `noMovingBall` 且保留充能，达到 8 球上限时发 `splitBlocked`，页面 toast「球数已满 · N 颗未分裂」。新增 `debuff` 砖与 `shrink/speed/reverse` 三种限时减益，击破时发 `debuffTriggered`，由 `debuffBar` 显示状态条，挡板按减益着色。移除全部激光绘制与光束特效。
- 决定（2026-10-23，技能即时施放，取代上述充能/限时口径）：技能取消 `charges`、`activateSkill`、`slotPress` 与所有时长，改为 `castSkill()` 接到即施放；`state.skillStacks` 记录加宽/减速层数（×1.4 封顶 2.0×、×0.85 封底 0.5×，本关永久），多球/分裂即时生效。技能格只作广告入口与状态显示，点击直接拉广告、无确认弹层，封顶/无目标时不拉。奖励掉落改为只在可生效技能中随机，四格全封顶不掉；接住时若已封顶则作废。减益改为「击碎必掉对应类型掉落物、接到才生效」，层数永久、状态条只显示图标 + 层数；清除率与 HUD 百分比删除，只保留剩余/总数。
- 验证：`corepack pnpm test` 57 项通过（shared 覆盖自定义失败线、充能上限、奖励砖必掉、满格不生成掉落、旧档字段丢弃、拾取只充能不自动生效、分裂与三种减益）；浏览器确认无首页直达最高关、四类弹层无 home、奖励砖掉落可被挡板拾取；四格常驻、空槽广告、广告中时间冻结、补给后充能 +1、拖动跨技能栏不断手；真实 PointerEvent 按下后拖出技能格不消耗充能，原地点击才释放；分裂 1→2 球、无移动球拒绝保留充能、三种减益状态条与挡板缩短（97.5/150）实测正常。2026-10-23 改造后的验证结果见 `docs/verify/REQ-001-verification.md`。
- 后续（2026-10-23，直接开局与递增计数）：删除 `preRound` 弹层与开始按钮，`start()` 直接 `paused=false` 并提示「点击棋盘发球」；HUD 改为递增的已清除/总数，删掉「剩余 / 总数」与「可破坏」；预开局、失败、结果页的「可破坏」文案一并清除。验证 67 项测试与 22 项浏览器断言通过。
- 后续（2026-10-24，大球替换多球）：`SKILL_IDS` 改为 `['bigBall', 'widePaddle', 'split', 'slow']`；`castSkill('bigBall')` 置 `state.bigBall`、所有球半径 ×1.6 并设 `piercing`，之后 `addBall()` 继承；穿透碰撞单列分支——普通/奖励/减益砖进入即破，硬砖每次进入扣 1 点（`pierced` 按砖 id 去重、离开清除），障碍走普通反弹；`skillCanCast('bigBall')` 在已施放后返回 false，技能格显示「已满」。奖励掉落池显式排除 `bigBall`，池内技能都不可用时 `skillFull` toast 改为「暂时没有可生效的技能」。`syncPaddleWidth` / 球半径 / 掉落半径接入 `state.board.scale`，挡板底边距改为 `PADDLE.bottomInset = 8`。
- 验证（2026-10-24）：`corepack pnpm test` 71 项通过（新增大球放大/穿透/一次性、奖励池排除大球、缩放关卡几何）；浏览器 L1 施放大球后快照 `ballRadius=31.68`、`piercing=[true]`、`bigBall=true`、技能格不可再施放；三端构建与 `verify:dist` 通过。

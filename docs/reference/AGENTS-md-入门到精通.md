**AGENTS.md 文件的核心作用及最佳实践解析**

本视频详细介绍了在使用 Claude Code 或 Codex 等 AI 编程辅助工具时，关键的配置文件 **AGENTS.md（Codex 对应为 AGENTS.md）** 的重要性、分类、编写、维护和优化方法，帮助用户最大化提升 AI 协作效率与准确性。

**1. AGENTS.md 的定义与重要性**

AGENTS.md 是一种系统指令文件，当启动对话时，Claude Code 会自动将其中内容注入到 AI 的 **Context Window**，作为 AI 工作的最高指令原则。

• 作用：系统启动即读入，**强制 AI 遵守其中指令**。

• 效果：避免每次新对话重复解释项目结构和规则，极大节省沟通时间。

• Codex 的等效文件名为 AGENTS.md，功能完全相同。

**核心结论：写好AGENTS.md 是使用 AI 的高投资回报行为。**

**2. AGENTS.md 的层级分类及适用范围**

AGENTS.md 可以存在不同文件夹层级，影响适用范围不同，AI 会依层级**叠加规则**统一执行：

• Nested Level 接近实际工作文件，规则最具体最直接生效。

• AI 会逐级覆盖、合并上述规则，最后以最接近工作内容的规则为主。

• 用户务必根据个人习惯、团队规则及子模块特殊需求，将规则合理拆分存放。

**3. AGENTS.md 的初始创建与内容取舍指南**

**3.1 使用官方指令快速生成**

• 通过命令 /init，Claude Code 会根据项目文件内容自动扫描，生成初版 AGENTS.md 模板。

• 生成内容通常包括项目简介、启动构建流程、使用框架、文件结构及部分开发习惯。

**3.2 自动生成内容的问题**

• 自动生成包含很多 **AI 本身能自动探查到的信息**（如 package.json），重复写入会造成资源浪费。

• 加入过多冗余信息会占用 Context Window，让 AI 的 **Instruction Budget** 被无关信息占满，导致真正重要的任务规则被淹没。

• 所以，必须对自动生成内容逐条审核，做**减法**。

**3.3 减法三大判定问题**

评估是否需留在 AGENTS.md，问自己：

1\. **此信息 AI 自己能快速探知吗？**\
能被 Explore subagent 自动发现的，就不必写。

2\. **该规则是否适用于大多数工作？**\
如仅针对特定子文件夹，应放入对应 Nested AGENTS.md。

3\. **此规则是否具有持久性？**\
短期临时的规定（如过时 API）不宜长期保留。

**3.4 加法五大经验补充问题**

筛选后，需要补充 AI 无法自动理解、但关键的"隐性知识"：

• 有没有**绝对不能错的规定**？（如价格必须含税）

• 有没有**固定的处理流程**？（如价格修改流程）

• 修改一环后，哪些地方要同时更新？（连锁联动关系）

• 何为修改完成标准？（测试、检查要求）

• AI 遇到陌生问题时，去哪里找答案？（知识文档及指南地址）

**3.5 内容存放后续处理**

• 客观现状和公共信息由 AI 自行探索。

• 某些复杂流程可写为 Skill 或用 Hook 机制实现。

• 极重要的死罪（如 API key 不得上传）应用 Hook 编程机制强制拦截。

**4. AGENTS.md 的持续维护与优化**

**4.1 维护原则："新增 + 修剪"**

• **新增**：结合使用体感，由 /insights 指令生成历史交互报告，找出反复发生的坑，自动推荐可加入的规则片段。

• **修剪**：

> • 删除因模型升级而变多余的规则。官方示例中，新模型 Fable 5 & Opus 5 删减超过 80% 旧规则且性能不降反升。
>
> • 删除与实际项目或流程不符的过时规则。
>
> • 参考最新官方 Prompting Guide，保持规则最佳实践性。

**4.2 维护工具辅助**

• 针对模型版本差异，维护提示会自动对比差异并建议规则修正。

• AGENTS.md 与 AGENTS.md 可用文件内 reference 方式同步管理，避免重复维护。

**4.3 经典误区**

• 害怕删掉规则导致被坑，实际"老旧多余规则"反而限制 AI 智能。

• 将 AGENTS.md 当作固定不变的规格书，忽略 AI 和项目动态演化的重要性。

**5. 视频核心总结**

• **AGENTS.md 及 AGENTS.md 是 AI 项目协作的最高指令档。**

• 不同层级文件影响范围不同，合理分类是效率的关键。

• 利用 /init 快速起步，但必须人工筛删再优化。

• 内容重点放隐性规则、固定流程、不可犯禁忌和重要检查。

• 长期维护依赖"新增"与"修剪"，用 /insights 协助发现盲点。

• 定期对照最新官方 Prompting Guide 做版本兼容调整。

• AI 合作中，规则是"不断成为"的过程，保持动态迭代，效率更高。

**关键术语表**

通过合理设计、持续优化和动态维护 AGENTS.md，用户可以确保每次 AI 开发协作中都最大程度发挥模型能力，减少错误和重复沟通，实现高效稳定的开发体验。

# 规则模拟固定步长、显式种子

`packages/shared` 的玩法模拟以固定步长 `1/120s` 推进（帧循环累加器，单帧最多补 8 步），随机性统一走 `xorshift32`，种子由关卡 id 与关卡尝试计数显式构造，禁止 `Math.random()`、`Date.now()` 等外部状态。球间弹性碰撞让局面天然混沌，只有确定性模拟才能写「同种子同输入逐帧一致」的回归测试，并把线上问题复现成固定用例。

考虑过的替代方案：可变 delta + `Math.random()`（实现简单，但结果不可复现、物理调参容易随帧率漂移、广告复活等结算难以稳定回归）。

后果：所有随机逻辑必须从 state 里的 RNG 取值，新增玩法不能图省事直接调 `Math.random()`；跨端浮点表现需在真机走查中确认。

关联：REQ-001；测试口径见 `.scratch/mosaic-core/spec.md`「Testing Decisions」。

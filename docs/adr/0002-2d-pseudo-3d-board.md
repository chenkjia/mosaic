# 棋盘用 2D 平面坐标，砖块做伪 3D

原版 Midnight Crushers 是带透视的 3D 棋盘；本作的所有玩法坐标（球、挡板、砖块）都在 2D 平面上计算，砖块仅通过圆角、高光、底部内阴影、描边与投影合成宝石质感，不引入透视变换、相机或 WebGL。这样物理可确定性测试、触控映射简单、三端性能可控，同时保住原版「彩色宝石拼图」的观感。

考虑过的替代方案：真 3D / 透视投影（碰撞与输入复杂度陡增，且与 canvas-minigame 的性能约束冲突）、直接用位图砖块（无法按状态换色与做裂纹，且 16 色关卡调色板复用困难）。

后果：没有真实光照与视角变化，立体感全部依赖绘制细节；砖块视觉状态（裂纹、斜纹）必须做冗余编码，不能只靠颜色区分。

关联：REQ-001；用户确认的玩法口径见根 [AGENTS.md](../../AGENTS.md)「玩法定案」。

# Mosaic 真机走查清单（微信 / 抖音）

- 版本：0.1.0
- 日期：2026-10-21（初版），2026-10-22（无首页 / 奖励砖必掉 / 6 块分散奖励砖与点击释放复核）
- 适用：`dist/wechat`、`dist/douyin`
- 执行者：用户（agent 不具备真机与平台后台权限）
- 回报方式：按编号记录「通过 / 失败 + 截图 / 录屏 + 机型与基础库版本」，失败项回写 `logs/agent-activity.md` 后修复。

## 0. 准备

1. `corepack pnpm test && corepack pnpm build && corepack pnpm verify:dist` 全绿。
2. 广告：在 `apps/game/src/config/ads.js` 填入平台后台申请的激励视频广告位 ID（可只填 `AD_UNIT_ID`，或按 `revive` / `extraBall` / `skillCharge` 分点位填 `AD_UNIT_IDS`），重新构建对应平台。
3. 微信开发者工具：导入 `dist/wechat`，项目类型「小游戏」，填入正式 AppID；抖音开发者工具：导入 `dist/douyin`，类型「小游戏」。
4. 基础库使用当前稳定版；准备至少一台 iOS 与一台中低端 Android。
5. 每次验证存档类场景前，在开发者工具 Storage 面板删除键 `mosaic.save.v1`（或清除全部缓存），再重新编译。
6. 真机调试打开 Console，启动应看到 `[game] boot 0.1.0` 与 `[boot] play 0.1.0`；小游戏包内不应出现 `__MOSAIC_DEBUG__`。

场景速查（关卡编号用 web 调试 `startLevel(id)` 或逐关推进；清档后从第 1 关开始）：

| 场景 | 关卡 | 说明 |
|---|---|---|
| 障碍 / 奖励砖 / 基础反弹 | 1 | 232 块可破坏，14 硬砖、4 障碍、6 奖励砖（分散），球速 560 |
| 硬砖密集 | 10 / 20 / 30 | 硬砖 34 / 51 / 120，球速 614 / 674 / 734 |
| 花卉主题 | 11–20 | 第 11 关 133 块可破坏，球速 620 |
| 风景主题 | 21–30 | 第 21 关 269 块可破坏，球速 680 |
| 低球速易操作 | 1 | 适合先验证发球、挡板、暂停 |
| 高压力 / 8 球 | 30 + 多球技能 | 硬砖 120、障碍 6，适合性能与球数上限观察 |

## 1. 启动与包体

| # | 步骤 | 判据 | 场景构造 |
|---|---|---|---|

| 1.4 | 检查屏幕方向 | 始终竖屏，旋转设备不进入横屏 | 真机旋转 |
| 1.5 | 刘海 / 安全区 | HUD 不被遮挡，技能栏与提示不被 home indicator 裁切 | iPhone 刘海机型 |

## 8. 平台差异重点

### 微信

- 单包：`game.json` 不含 `subpackages`；开发者工具文件树只有 `game.js`、`game.json`、`assets/`。
- 分享使用 `wx.shareAppMessage`；封面路径为包内根路径 `assets/share/cover.png`。
- 激励视频使用 `wx.createRewardedVideoAd`；旧基础库 `onClose` 不传 `res` 时按完整观看处理。
- 检查右上角菜单分享是否与游戏内分享行为一致。

### 抖音

- 单包：`game.json` 不含 `subPackages`；确认产物直接以根目录 `game.js` 启动。
- 分享使用 `tt.shareAppMessage`；如平台要求 `templateId` / 频道参数，按后台要求补充后复验。
- 激励视频使用 `tt.createRewardedVideoAd`；确认关闭回调的 `isEnded` 语义。
- 检查录屏/直播 SDK 是否与触摸、音频冲突（V1 未接入，只做回归确认）。

## 9. 通过标准

- 第 1–8 节所有标「必须」的项通过；广告、分享、复活、切后台、存档持久化为硬门槛。
- 控制台无 error；允许的日志仅启动、版本标记。
- 三端包体上传平台后台通过，单包不超预警线。
- 失败项附截图/录屏、机型、系统版本、基础库版本、复现步骤与关卡编号。

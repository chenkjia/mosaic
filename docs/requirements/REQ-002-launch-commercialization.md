# REQ-002 上线与商业化待办

状态：待排期（V1 不实施，只登记待办与前置依赖）。参考先例：`~/game/qian`（软著材料、广告 adapter、推广方案）。

## 已定边界

- V1 只做激励视频与分享，**不做内购、不做虚拟支付、不做插屏/原生广告**。
- V1 不建服务端；广告、分享、存档全部走平台能力与本地存储。
- 上线所需资质、提审、真机操作由用户执行；agent 负责材料、代码与走查清单。

# REQ-001 Mosaic 核心玩法 V1

状态：V1 已实现（2026-10-21），数据层、三端构建与 web 浏览器流程通过；真机走查待用户执行。验证报告见 [`docs/verify/REQ-001-verification.md`](../verify/REQ-001-verification.md)，真机清单见 [`docs/verify/device-checklist.md`](../verify/device-checklist.md)。

## 范围

### 1. 平台与构建

- web / 微信 / 抖音三端，一套 ES modules 源码，esbuild 多入口打包至 `dist/{web,wechat,douyin}`。
- 单包交付：游戏代码与全部位图资源打进同一个包，不声明分包；微信/抖音模板仅保留竖屏等基础字段。
- 输出体积检查一行：单包总量；2MB 预警、18MB 上限预警。

### 2. 局内核心

- 竖屏；挡板横向位置直接跟随触点，点击发球；挡板击球点决定反弹角度。
- 2D 平面棋盘 + 伪 3D 宝石砖块（圆角方砖 + 高光/内阴影/投影），无透视、无真 3D。
- 球间弹性碰撞保留，同屏球数上限 8。
- 球色三档：蓝=普通；红=强力（可破硬砖）；绿=分裂（命中后分裂，受上限约束）。
- 砖块四类：普通（1 击）、硬砖（2 击起、裂纹递进）、障碍（不可破坏、不计入清除率分母）、奖励砖（掉落金币或技能）。
- 清除率 = 已破坏可破坏砖块 ÷ 可破坏砖块总数，HUD 显示 `CLEARED · x%`。
- 过关：可破坏砖块清零 → 结算 → 自动进入下一关。
- 失败：球全部掉落 → 失败面板；可看激励视频复活一次（本关），否则重开本关。
- 无星级、无评分、无关卡选择页；存档只记最高关，启动从最高关继续。

### 3. 技能、金币与存档

- 技能槽 4 格，默认容量 2 格，金币扩容至 4 格（第 3 格 200、第 4 格 500）。
- 四个技能：多球（+2 球）、加宽挡板（+40%，15 秒）、激光（10 秒）、减速（-30%，10 秒）。
- 技能唯一来源是奖励砖掉落；局内点击技能槽释放。
- 金币来源：过关结算（20/关）与激励视频（结算双倍）；只用于扩容技能槽。
- 本地存档：最高关、金币、技能槽容量；读写收口单点，损坏降级重置。

### 4. 关卡内容

- V1 共 30 关，3 主题 × 10 关（动物 / 花卉 / 风景）。
- 关卡由「像素画源图 → 量化到 16 色 → 切格 → 关卡 JSON」管线产出；源图用 AI 生成后人工微调。
- 关卡 JSON 经 schema 校验；每关可破坏砖块数 > 0，网格不超过 21 列 × 28 行。

### 5. 商业化（V1 范围）

- 激励视频三个点位：失败复活（每关 1 次）、开局额外球、结算双倍金币。
- 未配置 `AD_UNIT_ID` 时走模拟广告（与 web 同链路）；配置后自动切平台 SDK。
- 分享入口：分享当前关卡画面/进度，V1 不带奖励。
- 不做内购、不做虚拟支付、不做插屏/原生广告。

### 6. 界面与音频

- 页面：启动 loading、主页（继续/开始）、局内 HUD（金币、关卡号、清除率、技能槽、暂停）、结算、失败、广告模拟层、设置（音效/音乐开关）。
- 音乐 1 首 BGM + 音效（击砖、反弹、掉落、过关、失败、按钮），资源可后置，但接口先留。

## 验收标准

1. **构建**：`pnpm --filter ./apps/game run build` 产出 `dist/web`、`dist/wechat`、`dist/douyin`；单包体积一行打印；产物 grep 无调试探针符号。
2. **确定性物理（数据层）**：同一种子、同一输入序列跑 600 步，两次结果逐帧一致；球-砖、球-墙、球-挡板、球-球碰撞各不少于 3 条断言；所有坐标断言为有限值。
3. **清除率**：障碍不计入分母；可破坏砖块清零时清除率为 100% 并触发过关。
4. **球数上限**：分裂与额外球在 8 球时不再生成；球-球碰撞后无重叠粘连。
5. **球色**：红球可破坏硬砖；绿球命中后分裂一次；蓝球对硬砖伤害为 1。
6. **技能与金币**：默认 2 槽；200/500 金币扩到 3/4 槽；四个技能效果均可用数据层断言（多球数量、挡板宽度、激光伤害、减速倍率）。
7. **存档**：最高关/金币/槽容量经序列化往返一致；损坏存档降级为初始值且不崩溃。
8. **广告**：无 `AD_UNIT_ID` 时三处入口均走模拟广告并正确发奖；复活每关仅一次；双倍金币结算数值为 2 倍。
9. **关卡**：30 关 JSON 全部通过 schema 校验；每关可破坏砖块数 > 0；三主题各 10 关。
10. **视觉（确定性页面）**：`apps/demo/demo1/` 静态页在 390×844、768×1024、750 基准三种尺寸下无溢出、无遮挡；宝石砖块的高光/阴影/圆角走查通过。
11. **浏览器核验**：主页 → 开局 → 过关 → 下一关 → 失败 → 复活链接路可自动点击走通，控制台无报错。
12. **人工清单**：产出真机走查清单（微信/抖音），含步骤、判据、场景构造方法。

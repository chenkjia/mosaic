## 范围

### 1. 平台与构建

- web / 微信 / 抖音三端，一套 ES modules 源码，esbuild 多入口打包至 `dist/{web,wechat,douyin}`。
- 单包交付：游戏代码与全部位图资源打进同一个包，不声明分包；微信/抖音模板仅保留竖屏等基础字段。
- 输出体积检查一行：单包总量；2MB 预警、18MB 上限预警。

### 2. 局内核心

- 竖屏；操作区（HUD 下沿到屏幕最底、左右贴屏）内按下即接管挡板横向位置并跟随到抬手，越出棋盘、压到技能栏都不打断；空白处按下同时发球；挡板击球点决定反弹角度。
- 2D 平面棋盘 + 伪 3D 宝石砖块（圆角方砖 + 高光/内阴影/投影），无透视、无真 3D。
- 球间弹性碰撞保留，同屏球数上限 8。
- 球色三档：蓝=普通；红=强力（可破硬砖）；绿=分裂（命中后分裂，受上限约束）。
- 砖块五类：普通（1 击）、硬砖（2 击起、裂纹递进）、障碍（不可破坏、不参与过关判定）、奖励砖（每关 6 块、尽量分散布置；击碎必掉技能掉落物）、减益砖（类型固定可见，击碎必掉减益掉落物）。
- 减益砖三种类型：挡板缩短 0.65×；球速 ×1.3；方向反转。挡板接到减益掉落物才生效，漏接不生效；效果本关永久，同类可叠加（缩小/加速乘法叠加，反向为二元状态），颜色 + 图标双重编码。
- HUD 不显示清除率或百分比；居中显示剩余可破坏砖数与总数。过关判定为可破坏砖块清零，障碍不参与。
- 过关：可破坏砖块清零 → 结算 → 自动进入下一关。
- 失败：球全部越过失败线（技能栏上沿）→ 失败面板；可看激励视频复活一次（本关），否则重开本关。
- 无星级、无评分、无关卡选择页；存档只记最高关，启动直接进入最高关预开局弹层，不设首页。

### 3. 技能、失败线与存档

- 四格技能栏固定常驻，顺序为多球 / 加宽 / 分裂 / 减速；不储存充能或次数，技能格只是广告入口与本关状态展示。
- 点击技能格直接拉起激励视频，不再有确认层；看完立即施放。当前无法产生效果时置灰并标注「已满 / 无目标」；准备阶段也可看技能广告。
- 四个技能效果：多球（每次 +2 球，8 球上限）、加宽挡板（每次 +40% 基础宽度，1.4→1.8→2.0 封顶，本关永久）、分裂（场上每颗移动中的球同时分裂出 1 颗同色球，±30°、同速，停泊球不参与，8 球上限）、减速（每次 ×0.85，0.85→0.72→0.61→0.52→0.5 封底，本关永久）；加宽/减速格显示当前倍率。
- 技能来源：奖励砖掉落物被挡板接到立即施放，或点击技能格看广告后立即施放；奖励掉落只在当前还能生效的技能中随机，四个都到顶时不掉并提示。
- 技能与减益只在本关有效：过关、失败重开、进入下一关清零；复活保留。
- 失败线 = 技能栏上沿；球与未接住的掉落物越过即丢失，全部球丢失判失败。棋盘底边到失败线之间为下落带，只保留左右边界。
- 本地存档：最高关、音效/音乐开关；V1 无金币、无技能槽容量（2026-10-22 用户确认移除金币与扩容）。读写收口单点，损坏降级重置。

### 4. 关卡内容

- V1 共 30 关，3 主题 × 10 关（动物 / 花卉 / 风景）。
- 关卡由「像素画源图 → 量化到 16 色 → 切格 → 关卡 JSON」管线产出；源图用 AI 生成后人工微调。
- 关卡 JSON 经 schema 校验；每关可破坏砖块数 > 0，网格不超过 21 列 × 28 行。
- 难度以可破坏砖数为主轴，按关卡号分带：1–3 关 70–90；4–7 关 90–120；8–12 关 120–150；13–16 关 150–175；17–19 关 175–199；20–24 关 200–250；25–30 关 250–330。
- 早期关卡像素画缩到较少行数，20 关后接近满尺寸；底三行（25–27）永远留空，可见最底砖块贴住第 24 行，与挡板间隙约 52.5px。
- 减益砖数量随关卡递增：1–3 关 0 块，4–7 关 1 块，8–12 关 2 块，13–19 关 3 块，20–30 关 4 块；类型按关卡轮换，三种类型均衡。

### 5. 商业化（V1 范围）

- 激励视频两个点位：失败复活（每关 1 次）、技能施放（点击技能格观看，广告期间整局暂停）。
- 未配置 `AD_UNIT_ID` 时走模拟广告（与 web 同链路）；配置后自动切平台 SDK。
- 分享入口：分享当前关卡画面/进度，V1 不带奖励。
- 不做内购、不做虚拟支付、不做插屏/原生广告。

### 6. 界面与音频

- 页面：启动 loading、局内 HUD、预开局弹层、结算、失败、广告模拟层、暂停设置（音效/音乐开关）；无首页。
- 局内 HUD：左上暂停按钮 + 关卡号；居中显示剩余 / 总可破坏砖数，不显示清除率或百分比；右上完全留空（给小游戏平台胶囊）。
- 局内界面：游戏面板与棋盘同宽（714），从 HUD 下沿铺到屏幕物理最底，左右各留 18 背景边距；卡内分隔线正对四格技能栏上沿，即失败线。技能栏四格等宽（165×112，间距 18）铺满棋盘宽，底边自屏幕底向上避让 `safeBottom` 并留 24；局内 toast 画在技能栏上方。
- 音乐 1 首 BGM + 音效（击砖、反弹、掉落、过关、失败、按钮），资源可后置，但接口先留。

## 验收标准

1. **构建**：`pnpm --filter ./apps/game run build` 产出 `dist/web`、`dist/wechat`、`dist/douyin`；单包体积一行打印；产物 grep 无调试探针符号。
2. **确定性物理（数据层）**：同一种子、同一输入序列跑 600 步，两次结果逐帧一致；球-砖、球-墙、球-挡板、球-球碰撞各不少于 3 条断言；所有坐标断言为有限值。
3. **过关统计**：障碍不参与；可破坏砖块清零时触发过关；HUD 不显示百分比，只显示剩余 / 总可破坏砖数。
4. **球数上限**：多球与分裂在 8 球时不再生成；球-球碰撞后无重叠粘连。
5. **球色**：红球可破坏硬砖；绿球命中后分裂一次；蓝球对硬砖伤害为 1。
6. **技能自动施放与叠加**：四格无充能、无点击释放；奖励掉落被挡板接到、或技能广告看完即施放。多球每次 +2（上限 8）、分裂每颗移动球各分裂一颗同色球（±30°，上限 8，停泊球不参与）、加宽按 1.4→1.8→2.0（封顶 2×）、减速按 0.85→0.72→0.61→0.52→0.5（封底 0.5×）本关永久叠加。加宽/减速到顶与多球/分裂到 8 球时按钮置灰「已满」，分裂无移动球时「无目标」；奖励掉落只在当前可生效技能中随机，四个都到顶时不掉并提示；技能过关/重开/下一关重置，复活保留。
7. **存档**：最高关、音效/音乐经序列化往返一致；旧档的 `coins` / `slotCapacity` 被丢弃且最高关保留；损坏存档降级为初始值且不崩溃。
8. **广告**：无 `AD_UNIT_ID` 时两处入口（复活 / 技能施放）均走模拟广告并正确发奖；复活每关仅一次；技能广告点击后直接拉起、无确认层，广告期间整局暂停且时间不推进；准备阶段也可用。开局 +1 球广告已移除。
9. **关卡**：30 关 JSON 全部通过 schema 校验；每关可破坏砖块数落在该关难度带内；每关奖励砖 6 块且在棋盘内尽量分散（生成器最远点采样，无人工聚簇）；减益砖数量符合递增规则；三主题各 10 关；底三行（25–27）留空，可见最底砖块在第 24 行，与挡板间隙 50–56px。
10. **减益砖**：三种类型固定可见并以颜色 + 图标双重编码；击碎必掉对应类型的减益掉落物（暗红菱形 + 图标），挡板接到才生效、漏接不生效；挡板 0.65×、球速 1.3× 按乘法叠加，方向反转为二元状态（不叠加），效果本关永久；状态栏显示图标 + 累计层数、不显示倒计时；减益砖不掉技能，砖块本身照常从剩余砖数中扣除。
11. **视觉（确定性页面）**：`apps/demo/demo1/` 静态页在 390×844、768×1024、750 基准三种尺寸下无溢出、无遮挡；宝石砖块的高光/阴影/圆角走查通过。
12. **浏览器核验**：冷启动直接进入最高关预开局弹层（只有「开始」）→ 开局 → 过关 → 下一关 → 失败 → 复活链路可自动点击走通；技能广告无确认层、看完即施放；暂停/结算/失败弹层均无「返回主页」，控制台无报错。
13. **人工清单**：产出真机走查清单（微信/抖音），含步骤、判据、场景构造方法。
14. **卡片铺底、失败线与手势接管**：布局断言游戏面板与棋盘同宽、下沿等于设计高度底边、分隔线等于四格技能栏上沿且 `failY = dividerY − board.y`；四格各 165 宽且首尾贴齐棋盘左右边；操作区通宽、技能栏底边不越入 `safeBottom`；HUD 暂停在左上、右上无控件。浏览器断言球落到技能栏上沿才丢失、视口变化后失败线跟随重算；从棋盘内按下拖到屏幕最底挡板持续跟随、卡片两侧窄边也能起手、抬手后停在最后位置、第二根手指按下不抢接管、HUD 空白处按下不动挡板。

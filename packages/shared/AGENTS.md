# packages/shared/AGENTS.md - 共享内核约束

> 就近规范，优先级高于根 AGENTS.md。适用范围：`packages/shared/`。

## 职责边界

- 存放前后端共享的类型、协议与纯逻辑（战斗、判定、经济等规则模拟）。
- 规则模拟必须纯 JavaScript：不得依赖渲染引擎、小游戏运行时 API、服务端框架 API 或 UI 层代码。
- 结算必须可复现：同一输入产生同一输出；随机性必须显式作为输入或可追踪状态，不得直接读取时间、全局随机数或外部状态。

## 协作

- 输出应描述可供游戏端播放、服务端校验的事件与最终结算，不直接操作渲染、网络或持久化。
- 类型、协议或规则变更须保持前后端兼容；破坏性变更先取得确认，并在相关需求/方案中记录。
- 数据源的派生产物（如 CSV→JSON 的转换输出）不手改，只跑转换脚本；手写配置与派生数据分开放。

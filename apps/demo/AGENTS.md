# apps/demo/AGENTS.md - 复刻与校准页规范

> 就近规范，优先级高于根 AGENTS.md。适用范围：`apps/demo/`。

## demoN 约定

- 一页一个独立子文件夹 `demoN/`，编号递增不复用；归档页保留供追溯。
- 原生 Canvas 2D、零构建、无 vendor、互不依赖，`file://` 直开。
- 页面用途两类：参考截图/设计稿的复刻页（可带叠加对照、网格、读数、减淡辅助）与校准工具页。
- 复刻页验收并 port 进游戏后即归档不再改动；后续修正只落正式版。
- 每页附带验收口径（对照基准、容差、核对项）；port 进 game 时按它做浏览器自动核验。

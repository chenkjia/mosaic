# demo1 · 伪 3D 宝石砖块校准页

零构建静态页，`file://` 直开。用于锁定正式版的砖块尺寸、缝隙、圆角、高光/内阴影/投影与 16 色马卡龙调色板。视觉确认后冻结，port 进 `apps/game` 后归档不再改动。

## 打开方式

- 直接双击 `index.html`，或浏览器打开 `file:///.../apps/demo/demo1/index.html`。
- 模拟视口：追加 `?view=390x844`、`?view=768x1024`、`?view=750x1334`（可叠加任意 `WxH`）。页面会按该尺寸跑真实布局计算，再等比缩放成面板显示，右上角 badge 报告视口、布局模式与缩放。
- `file://` 下部分浏览器会丢弃 query，改用 hash：`index.html#view=390x844`，效果一致。
- 按键：`G` 切换 21×28 网格，`H` 收起/展开规格面板。

## 规格表

| 项 | 值 |
| --- | --- |
| 设计宽 | 750 |
| 最小设计高 | 1334（不足时左右留边 fallback，不拉伸） |
| 棋盘 | 21 列 × 28 行 |
| 格宽 | 34 |
| 砖块内缩 | 1.5（可见砖块 31×31） |
| 棋盘尺寸 | 714 × 952，距顶 160，水平居中 |
| 圆角 | 7 |
| 调色板 | 16 色，砖色只能取自其中 |
| 四态 | 普通 / 硬砖（裂纹 + hp 圆点）/ 障碍（斜纹）/ 奖励（菱形 + 星芒） |

## 对照基准

- 风格：马卡龙糖果风；圆角方砖 + 宝石质感；不写实、不做真 3D。
- 光照：高光在顶部约 1/3，内阴影在底部，投影向下（统一光源方向）。
- 颜色编码必须带冗余编码：硬砖看裂纹与 hp 圆点，障碍看斜纹，奖励看菱形。

## 容差

- 尺寸、坐标、缝隙：±0.5 设计 px。
- 色值：必须命中 16 色调色板；渐变只做同色提亮/压暗混合。
- 同一格内高光、内阴影、投影方向一致，不允许逐砖翻转。
- 四态在 390×844（scale 约 0.48）下仍可辨；裂纹、斜纹、菱形不糊成色块。

## 核对项

1. 缝隙均匀：相邻砖块间距一致，无重叠、无错行。
2. 硬砖：裂纹清晰，hp 圆点数量与 hp 一致（2 或 3）。
3. 障碍：斜纹贯穿整砖且方向一致。
4. 奖励：白色菱形居中，星芒出现在右上角。
5. 网格：`G` 打开后，网格线与砖块边界对齐；标注 21×28 / cell 34 / board 714×952。
6. 三视口：390×844、768×1024、750×1334 均无溢出、无遮挡；HUD、棋盘、图例完整可见。
7. 布局：宽而矮的视口触发 fallback（左右留边），不出现纵向拉伸。

## 验收流程

1. `node --check demo1.js` 通过。
2. 浏览器按三个模拟视口截图走查，逐条核对上面的核对项。
3. 用户确认视觉后冻结参数；随后按本页 port 进正式版，并用浏览器自动核验比对。

# apps/server/AGENTS.md - 后端服务规范

> 就近规范，优先级高于根 AGENTS.md。未覆盖项以根规范为准。适用范围：`apps/server/`。

## 技术栈（项目开工时定案，改写本节）

- 默认基线：Node.js + 原生 JavaScript，异步统一 async/await；若定案 NestJS + TypeScript（qian 先例），改写本节并同步根 AGENTS.md 项目参数。
- 第三方依赖固定具体版本，禁止自动升级。
- 服务端代码不得依赖小游戏运行时 API 或客户端 UI 模块。

## 目录分层（原生 JS 基线）

`apps/server/src/` 按职责分层：

- `routes/` 请求入口、参数校验、响应封装
- `services/` 业务逻辑、事务编排
- `models/` 存储读写、数据结构
- `middlewares/` 鉴权、日志、异常捕获
- `config/` 环境变量、常量
- `utils/` 工具函数

## 协作边界

- 账号资产、存档、排行榜等字段属共享协议：变更须先确认，并同步更新 `packages/shared`，禁止前后端各自定义。
- 凭据、密钥、令牌与用户隐私数据不得写入代码、测试样例、日志或文档。
- 战斗、判定、经济等规则计算引用 `packages/shared` 的模型执行，避免维护一套独立规则。

## 编码与接口

- 强制边界判断与异常捕获，所有异步调用有 try/catch；最小变更，改动前必读相关文件。
- 接口附完整入参、出参、错误码与错误返回示例；统一响应结构 `{ code, msg, data }`。
- 数据变更类接口补充数据兼容与回滚方案；鉴权接口必须校验 token，禁止裸暴露。
- 环境变量经 `config/` 读取，禁止硬编码密钥；启动前自检端口、存储连接、依赖完整性；关键链路落日志，便于真机问题排查。
